แบบทดสอบก่อนเรียน (หน่วยที่ 3 การควบคุม)

1. หมวดหมู่บล็อกคำสั่งควบคุม (Control) ในโปรแกรม Scratch มีลักษณะและหน้าที่เด่นอย่างไร

ใช้สำหรับควบคุมลำดับการทำงาน เงื่อนไข และการทำซ้ำของโปรแกรม
ใช้สำหรับเปลี่ยนสีชุดตัวละครและฉากหลัง
ใช้สำหรับคำนวณทางคณิตศาสตร์และตัวเลข
ใช้สำหรับบันทึกเสียงและดนตรีประกอบ

5. บล็อกคำสั่ง "wait ( ) secs" มีหน้าที่หลักตามข้อใด

ลดความซ้ำซ้อนในการเขียนบล็อกคำสั่ง และทำให้โค้ดสั้นกระชับขึ้น

9. หากต้องการให้ตัวละครเดินไปข้างหน้า 10 ก้าว สลับกับการหยุดรอ 1 วินาที วนซ้ำแบบนี้ไปเรื่อยๆ ควรเลือกใช้บล็อกใดร่วมกัน

มีลักษณะเป็นช่องว่าง (C-shape) สำหรับนำบล็อกอื่นมาใส่ไว้ข้างใน

หน่วยที่ 3 การควบคุม

3.1 ความหมายของคำสั่งควบคุมการทำงาน

กลุ่มคำสั่งควบคุม (Control Blocks) เป็นบล็อกคำสั่งที่มีสีส้ม ใช้สำหรับควบคุมลำดับการทำงานของโปรแกรม การสร้างเงื่อนไขทางเลือก การทำซ้ำ (Loop) รวมถึงการจัดการเวลาและการหยุดการทำงาน เพื่อให้โปรแกรมเป็นไปตามตรรกะที่ต้องการ

3.2 คำสั่งเริ่มต้นการทำงาน (When Green Flag Clicked)

เป็นคำสั่งเหตุการณ์ (Events - สีน้ำตาลอ่อน/ส้มอมเหลือง) ที่ทำหน้าที่เป็นจุดเริ่มต้นหลักของโปรแกรม เมื่อผู้ใช้คลิกที่สัญลักษณ์ธงเขียวที่มุมบนของเวที ชุดคำสั่งที่ต่ออยู่ด้านล่างจะเริ่มทำงานทันที

3.3 คำสั่งการทำซ้ำ (Loop)

ใช้สำหรับสั่งให้บล็อกคำสั่งภายในทำงานซ้ำๆ กันหลายครั้ง ช่วยลดความซ้ำซ้อนในการต่อบล็อก คำสั่งที่นิยมใช้ ได้แก่ repeat ( ) สำหรับทำซ้ำตามจำนวนครั้งที่กำหนด และ forever สำหรับทำซ้ำไม่รู้จบ

3.4 คำสั่งการหน่วงเวลา (Wait)

ใช้คำสั่ง wait ( ) secs เพื่อหน่วงเวลาหรือหยุดรอการทำงานตามระยะเวลาที่เป็นวินาทีที่กำหนด ช่วยให้การแสดงผลแอนิเมชันหรือขั้นตอนการทำงานมีความราบรื่นและดูเป็นธรรมชาติมากขึ้น

3.5 การใช้คำสั่งหยุดการทำงาน (Stop)

ใช้บล็อก stop ( ) เพื่อยุติการทำงานของโปรแกรม สามารถเลือกรูปแบบการหยุดได้ เช่น หยุดสคริปต์ทั้งหมด (all) หรือหยุดเฉพาะสคริปต์นี้ (this script) เพื่อควบคุมการจบการทำงานของตัวละครหรือเกมได้อย่างแม่นยำ
