แบบทดสอบก่อนเรียน (หน่วยที่ 4 ตัวแปร)

1. ข้อใดให้ความหมายของ "ตัวแปร (Variable)" ในโปรแกรม Scratch ได้ถูกต้องที่สุด

พื้นที่ในหน่วยความจำสำหรับเก็บข้อมูลที่สามารถเปลี่ยนแปลงค่าได้ตลอดการทำงาน
บล็อกคำสั่งสำหรับเปลี่ยนสีฉากหลังเวทีโดยอัตโนมัติ
เครื่องมือสำหรับบันทึกเสียงพูดของตัวละคร
ค่าคงที่ที่ไม่สามารถเปลี่ยนแปลงได้ตลอดการรันโปรแกรม

2. หากต้องการสร้างตัวแปรใหม่ขึ้นมาใช้งานในโปรแกรม Scratch ต้องไปที่หมวดหมู่บล็อกใด

Variables (ตัวแปร)
Operators (ตัวดำเนินการ)

Events (เหตุการณ์)

4. บล็อกคำสั่งใดใช้สำหรับกำหนดค่าเริ่มต้นให้กับตัวแปร เช่น กำหนดให้ตัวแปร score มีค่าเท่ากับ 0

change [score v] by (1)
show variable [score v]
hide variable [score v]

5. หากต้องการเพิ่มค่าคะแนนทีละ 1 แต้มเมื่อตัวละครเก็บเหรียญได้ ควรใช้บล็อกคำสั่งใด

change [HP v] by (-10)
set [HP v] to (-10)
change [HP v] by (10)

7. การแสดงค่าตัวแปรบนหน้าจอเวที (Stage) สามารถทำได้โดยวิธีใด

ตัวแปรจะแสดงบนหน้าจอโดยอัตโนมัติเสมอโดยไม่ต้องตั้งค่าใดๆ

8. ข้อใดคือประโยชน์หลักของการใช้ตัวแปรในการสร้างเกมด้วย Scratch

ช่วยในการเก็บบันทึกและติดตามข้อมูล เช่น คะแนน เวลา หรือพลังชีวิตของเกม
ช่วยให้โปรแกรมรันอินเทอร์เน็ตได้เร็วขึ้น
ช่วยลดขั้นตอนการวาดภาพตัวละคร
ทำให้ไม่ต้องใช้บล็อกคำสั่งควบคุมเงื่อนไข

9. หากต้องการซ่อนไม่ให้ตัวแปรแสดงอยู่บนหน้าจอเวที (Stage) ต้องใช้บล็อกคำสั่งใด

hide variable [variable name v]
show variable [variable name v]
set [variable name v] to (0)
stop all

10. ตัวเลือกใดในการสร้างตัวแปรที่ระบุว่าตัวแปรนี้ใช้งานได้สำหรับทุกตัวละครหรือเฉพาะตัวละครนี้เท่านั้น

11. หากเราต้องการนำค่าที่เก็บอยู่ในตัวแปรไปแสดงร่วมกับคำพูดของตัวละคร ควรนำบล็อกตัวแปรไปใส่ไว้ที่ใด

ช่องข้อความของบล็อกพูด (say ... for ... secs)
ช่องจำนวนก้าวของบล็อกเคลื่อนไหว (move ... steps)
ช่องสีของบล็อกรูปร่าง (change color effect)
ไม่สามารถนำตัวแปรไปใช้ร่วมกับบล็อกพูดได้

12. ข้อใดกล่าวถึงความแตกต่างระหว่างคำสั่ง `set` และ `change` ได้ถูกต้องที่สุด

set ใช้กำหนดค่าตายตัว ส่วน change ใช้เพิ่มหรือลดค่าจากค่าเดิมที่มีอยู่
set ใช้ลบตัวแปร ส่วน change ใช้สร้างตัวแปรใหม่
set ใช้กับตัวเลข ส่วน change ใช้กับตัวอักษรเท่านั้น
ทั้งสองคำสั่งมีหน้าที่และการทำงานเหมือนกันทุกประการ

หน่วยที่ 4 ตัวแปร (Variables)

4.1 ความหมายของตัวแปร

ตัวแปร (Variable) คือ พื้นที่ในหน่วยความจำของคอมพิวเตอร์ที่ถูกจองไว้สำหรับเก็บข้อมูล ค่าตัวเลข หรือข้อความ ซึ่งค่าเหล่านี้สามารถเปลี่ยนแปลง เพิ่มขึ้น ลดลง หรือถูกกำหนดใหม่ได้ตลอดเวลาในขณะที่โปรแกรมกำลังทำงาน เหมาะสำหรับการเก็บข้อมูลจำพวกคะแนน คะแนนชีวิต (HP) หรือเวลานับถอยหลัง

4.2 การสร้างตัวแปรใน Scratch

การสร้างตัวแปรในโปรแกรม Scratch สามารถทำได้โดยไปที่กลุ่มบล็อกสีส้มเข้ม Variables (ตัวแปร) แล้วคลิกที่ปุ่ม Make a Variable (สร้างตัวแปร) จากนั้นตั้งชื่อตัวแปร และเลือกระดับการใช้งานว่าต้องการให้ใช้ได้กับทุกตัวละคร (For all sprites) หรือใช้เฉพาะตัวละครนี้เท่านั้น (For this sprite only)

4.3 การกำหนดค่าให้ตัวแปร

เมื่อต้องการกำหนดค่าเริ่มต้นให้กับตัวแปร เช่น การตั้งค่าคะแนนเริ่มต้นเป็น 0 เมื่อเริ่มเกมใหม่ จะใช้บล็อกคำสั่ง set [ชื่อตัวแปร v] to (0) เพื่อกำหนดค่าเจาะจงลงไปในตัวแปรทันที นิยมวางไว้ใต้บล็อกเริ่มทำงาน (When Green Flag Clicked)

4.4 การเปลี่ยนค่าของตัวแปร

การปรับเปลี่ยนค่าของตัวแปรระหว่างที่โปรแกรมรันอยู่ เช่น เมื่อตัวละครเก็บไอเทมได้แล้วคะแนนเพิ่มขึ้น หรือโดนโจมตีแล้วเลือดลดลง จะใช้บล็อกคำสั่ง change [ชื่อตัวแปร v] by (จำนวนที่ต้องการ) ซึ่งจะช่วยเพิ่มหรือลดค่าจากค่าเดิมที่มีอยู่ เช่น change [score v] by (1) หรือ change [HP v] by (-10)

4.5 การแสดงค่าตัวแปรบนหน้าจอ

ค่าที่เก็บไว้ในตัวสามารถนำมาแสดงผลให้ผู้เล่นมองเห็นบนหน้าจอเวที (Stage) ได้ โดยการติ๊กเครื่องหมายถูกที่หน้าชื่อตัวแปรในหมวด Variables หรือใช้บล็อกคำสั่ง show variable [ชื่อตัวแปร v] เพื่อแสดงผล และใช้บล็อก hide variable [ชื่อตัวแปร v] เมื่อต้องการซ่อนไม่ให้แสดงบนหน้าจอ
