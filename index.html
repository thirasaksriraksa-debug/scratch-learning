หน่วยที่ 1 รู้จัก Scratch (Introduction to Scratch)

1.1 ความหมายของโปรแกรม Scratch

Scratch (สแครทช์) คือ ภาษาโปรแกรมในรูปแบบบล็อกคำสั่ง (Block-based Programming) ที่พัฒนาโดย MIT Media Lab เหมาะสำหรับการเรียนรู้การเขียนโปรแกรมขั้นพื้นฐาน ผู้เรียนสามารถลากและวางบล็อกคำสั่งมาต่อกันเพื่อสร้างเกม ภาพเคลื่อนไหว นิทาน หรือดนตรีได้อย่างง่ายดายโดยไม่ต้องพิมพ์โค้ดคำสั่งที่ซับซ้อน

1.2 ส่วนประกอบหลักของหน้าจอ Scratch

เมื่อเข้าสู่โปรแกรม Scratch หน้าจอการทำงานหลักจะแบ่งออกเป็นส่วนสำคัญ ดังนี้:

  • Block Palette (จานสีบล็อก): แหล่งรวมบล็อกคำสั่งตามหมวดหมู่สีต่างๆ เช่น การเคลื่อนไหว รูปร่าง เสียง เหตุการณ์ และการควบคุม
  • Script Area (พื้นที่เขียนสคริปต์): พื้นที่สำหรับนำบล็อกคำสั่งมาวางต่อกันเพื่อสร้างชุดคำสั่งให้ตัวละครทำงาน
  • Stage (เวที): พื้นที่แสดงผลลัพธ์การทำงานของโปรแกรมตามโค้ดที่เราเขียนไว้
  • Sprite List (รายการตัวละคร): ส่วนแสดงตัวละครทั้งหมดที่ใช้งานอยู่ในโปรเจกต์ สามารถเพิ่ม ลบ หรือเลือกตัวละครเพื่อเขียนโค้ดได้

1.3 แนวคิดพื้นฐานในการใช้งาน

การสั่งให้ตัวละคร (Sprite) ทำงานใน Scratch เริ่มต้นจากการเลือกตัวละครและฉากหลัง จากนั้นลากบล็อกเหตุการณ์ (Events) เช่น When [Green Flag] Clicked มาวางเป็นจุดเริ่มต้น และนำบล็อกคำสั่งการกระทำอื่นๆ มาต่อด้านล่าง เพื่อให้โปรแกรมรันเมื่อคลิกที่ธงเขียว

สื่อวิดีโอประกอบบทเรียน

ศึกษาเพิ่มเติมเกี่ยวกับการทำความรู้จักโปรแกรม Scratch จากวิดีโอด้านล่างนี้
