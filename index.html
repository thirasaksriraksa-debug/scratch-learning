หน่วยที่ 1 รู้จัก Scratch (Introduction to Scratch)

1.1 ความหมายของโปรแกรม Scratch

Scratch (สแครทช์) คือ ภาษาโปรแกรมในรูปแบบบล็อกคำสั่ง (Block-based Programming) ที่พัฒนาโดย MIT Media Lab เหมาะสำหรับการเรียนรู้การเขียนโปรแกรมขั้นพื้นฐาน ผู้เรียนสามารถลากและวางบล็อกคำสั่งมาต่อกันเพื่อสร้างเกม ภาพเคลื่อนไหว นิทาน หรือดนตรีได้อย่างง่ายดายโดยไม่ต้องพิมพ์โค้ดคำสั่งที่ซับซ้อน

1.2 ส่วนประกอบหลักของหน้าจอ Scratch

เมื่อเข้าสู่โปรแกรม Scratch หน้าจอการทำงานหลักจะแบ่งออกเป็นส่วนสำคัญ ดังนี้:

  • Block Palette (จานสีบล็อก): แหล่งรวมบล็อกคำสั่งตามหมวดหมู่สีต่างๆ เช่น การเคลื่อนไหว รูปร่าง เสียง เหตุการณ์ และการควบคุม
  • Script Area (พื้นที่เขียนสคริปต์): พื้นที่สำหรับนำบล็อกคำสั่งมาวางต่อกันเพื่อสร้างชุดคำสั่งให้ตัวละครทำงาน
  • Stage (เวที): พื้นที่แสดงผลลัพธ์การทำงานของโปรแกรมตามโค้ดที่เราเขียนไว้
  • Sprite List (รายการตัวละคร): ส่วนแสดงตัวละครทั้งหมดที่ใช้งานอยู่ในโปรเจกต์ สามารถเพิ่ม ลบ หรือเลือกตัวละครเพื่อเขียนโค้ดได้

1.3 แนวคิดพื้นฐานในการใช้งาน

การสั่งให้ตัวละคร (Sprite) ทำงานใน Scratch เริ่มต้นจากการเลือกตัวละครและฉากหลัง จากนั้นลากบล็อกเหตุการณ์ (Events) เช่น When [Green Flag] Clicked มาวางเป็นจุดเริ่มต้น และนำบล็อกคำสั่งการกระทำอื่นๆ มาต่อด้านล่าง เพื่อให้โปรแกรมรันเมื่อคลิกที่ธงเขียว

2.1 ความรู้เบื้องต้นเกี่ยวกับบล็อกเคลื่อนไหว

  • move (10) steps: สั่งให้ตัวละครเดินไปข้างหน้าตามทิศทางที่หันอยู่

หน่วยที่ 4 ตัวแปร (Variables)

4.1 ความหมายของตัวแปร

ตัวแปร (Variable) คือ พื้นที่ในหน่วยความจำของคอมพิวเตอร์ที่ถูกจองไว้สำหรับเก็บข้อมูล ค่าตัวเลข หรือข้อความ ซึ่งค่าเหล่านี้สามารถเปลี่ยนแปลง เพิ่มขึ้น ลดลง หรือถูกกำหนดใหม่ได้ตลอดเวลาในขณะที่โปรแกรมกำลังทำงาน เหมาะสำหรับการเก็บข้อมูลจำพวกคะแนน คะแนนชีวิต (HP) หรือเวลานับถอยหลัง

4.2 การสร้างตัวแปรใน Scratch

การสร้างตัวแปรในโปรแกรม Scratch สามารถทำได้โดยไปที่กลุ่มบล็อกสีส้มเข้ม Variables (ตัวแปร) แล้วคลิกที่ปุ่ม Make a Variable (สร้างตัวแปร) จากนั้นตั้งชื่อตัวแปร และเลือกระดับการใช้งานว่าต้องการให้ใช้ได้กับทุกตัวละคร (For all sprites) หรือใช้เฉพาะตัวละครนี้เท่านั้น (For this sprite only)

4.3 การกำหนดค่าให้ตัวแปร

เมื่อต้องการกำหนดค่าเริ่มต้นให้กับตัวแปร เช่น การตั้งค่าคะแนนเริ่มต้นเป็น 0 เมื่อเริ่มเกมใหม่ จะใช้บล็อกคำสั่ง set [ชื่อตัวแปร v] to (0) เพื่อกำหนดค่าเจาะจงลงไปในตัวแปรทันที นิยมวางไว้ใต้บล็อกเริ่มทำงาน (When Green Flag Clicked)

4.4 การเปลี่ยนค่าของตัวแปร

การปรับเปลี่ยนค่าของตัวแปรระหว่างที่โปรแกรมรันอยู่ เช่น เมื่อตัวละครเก็บไอเทมได้แล้วคะแนนเพิ่มขึ้น หรือโดนโจมตีแล้วเลือดลดลง จะใช้บล็อกคำสั่ง change [ชื่อตัวแปร v] by (จำนวนที่ต้องการ) ซึ่งจะช่วยเพิ่มหรือลดค่าจากค่าเดิมที่มีอยู่ เช่น change [score v] by (1) หรือ change [HP v] by (-10)

4.5 การแสดงค่าตัวแปรบนหน้าจอ

ค่าที่เก็บไว้ในตัวสามารถนำมาแสดงผลให้ผู้เล่นมองเห็นบนหน้าจอเวที (Stage) ได้ โดยการติ๊กเครื่องหมายถูกที่หน้าชื่อตัวแปรในหมวด Variables หรือใช้บล็อกคำสั่ง show variable [ชื่อตัวแปร v] เพื่อแสดงผล และใช้บล็อก hide variable [ชื่อตัวแปร v] เมื่อต้องการซ่อนไม่ให้แสดงบนหน้าจอ

หน่วยที่ 5 เงื่อนไข (Conditions)

5.1 ความหมายของคำสั่งเงื่อนไข

คำสั่งเงื่อนไข (Conditional Statement) คือ คำสั่งที่ใช้สำหรับตัดสินใจและควบคุมการทำงานของโปรแกรมให้เลือกกระทำเส้นทางใดเส้นทางหนึ่ง ตามผลลัพธ์ของการตรวจสอบเงื่อนไขว่าเป็นจริง (True) หรือเป็นเท็จ (False) เปรียบเสมือนการตัดสินใจในชีวิตประจำวัน เช่น "ถ้าฝนตก จะกางร่ม แต่ถ้าฝนไม่ตก จะไม่กางร่ม"

5.2 คำสั่ง If

คำสั่ง if <...> then เป็นคำสั่งเงื่อนไขพื้นฐาน ใช้สำหรับตรวจสอบเงื่อนไข หากผลลัพธ์การตรวจสอบเป็นจริง (True) โปรแกรมจะทำชุดคำสั่งที่อยู่ภายในบล็อก if นั้น แต่ถ้าผลลัพธ์เป็นเท็จ (False) โปรแกรมจะข้ามคำสั่งนั้นไปทำคำสั่งถัดไปโดยไม่มีการทำงานสำรอง

5.3 คำสั่ง If–Else

คำสั่ง if <...> then ... else ... เป็นคำสั่งเงื่อนไขทางเลือก เมื่อมีการตรวจสอบเงื่อนไขแล้ว หากเป็นจริงจะทำงานในส่วนของ then แต่หากเงื่อนไขเป็นเท็จ โปรแกรมจะหันไปทำงานในส่วนชุดคำสั่งที่อยู่ภายในช่อง else แทน ช่วยให้สามารถจัดการทางเลือกได้ครบทั้งสองกรณี

5.4 การใช้ตัวดำเนินการเปรียบเทียบ

การสร้างเงื่อนไขใน Scratch จำเป็นต้องอาศัยกลุ่มบล็อกสีเขียวอ่อน Operators (ตัวดำเนินการ) เข้ามาช่วยในการเปรียบเทียบข้อมูล เช่น เครื่องหมายมากกว่า (>), น้อยกว่า (<), หรือเท่ากับ (=) รวมถึงตัวดำเนินการทางตรรกะ เช่น and, or และ not เพื่อสร้างเงื่อนไขที่ซับซ้อนและแม่นยำยิ่งขึ้น

5.5 การใช้เงื่อนไขร่วมกับตัวแปร

การนำเงื่อนไขมาทำงานร่วมกับตัวแปร (Variables) เช่น การตรวจสอบค่าคะแนน score หรือพลังชีวิต HP เพื่อควบคุมเหตุการณ์สำคัญในเกม เช่น "ถ้า HP น้อยกว่าหรือเท่ากับ 0 ให้แสดงข้อความ Game Over" หรือ "ถ้า score เท่ากับ 10 ให้เปลี่ยนฉากไปด่านถัดไป" ซึ่งช่วยเพิ่มความสมจริงและสร้างกลไกการเล่นเกมใน Scratch ได้อย่างสมบูรณ์

หน่วยที่ 1 รู้จัก Scratch (Introduction to Scratch)

1.1 ความหมายของโปรแกรม Scratch

Scratch (สแครทช์) คือ ภาษาโปรแกรมในรูปแบบบล็อกคำสั่ง (Block-based Programming) ที่พัฒนาโดย MIT Media Lab เหมาะสำหรับการเรียนรู้การเขียนโปรแกรมขั้นพื้นฐาน ผู้เรียนสามารถลากและวางบล็อกคำสั่งมาต่อกันเพื่อสร้างเกม ภาพเคลื่อนไหว นิทาน หรือดนตรีได้อย่างง่ายดายโดยไม่ต้องพิมพ์โค้ดคำสั่งที่ซับซ้อน

1.2 ส่วนประกอบหลักของหน้าจอ Scratch

เมื่อเข้าสู่โปรแกรม Scratch หน้าจอการทำงานหลักจะแบ่งออกเป็นส่วนสำคัญ ดังนี้:

  • Block Palette (จานสีบล็อก): แหล่งรวมบล็อกคำสั่งตามหมวดหมู่สีต่างๆ เช่น การเคลื่อนไหว รูปร่าง เสียง เหตุการณ์ และการควบคุม
  • Script Area (พื้นที่เขียนสคริปต์): พื้นที่สำหรับนำบล็อกคำสั่งมาวางต่อกันเพื่อสร้างชุดคำสั่งให้ตัวละครทำงาน
  • Stage (เวที): พื้นที่แสดงผลลัพธ์การทำงานของโปรแกรมตามโค้ดที่เราเขียนไว้
  • Sprite List (รายการตัวละคร): ส่วนแสดงตัวละครทั้งหมดที่ใช้งานอยู่ในโปรเจกต์ สามารถเพิ่ม ลบ หรือเลือกตัวละครเพื่อเขียนโค้ดได้

1.3 แนวคิดพื้นฐานในการใช้งาน

การสั่งให้ตัวละคร (Sprite) ทำงานใน Scratch เริ่มต้นจากการเลือกตัวละครและฉากหลัง จากนั้นลากบล็อกเหตุการณ์ (Events) เช่น When [Green Flag] Clicked มาวางเป็นจุดเริ่มต้น และนำบล็อกคำสั่งการกระทำอื่นๆ มาต่อด้านล่าง เพื่อให้โปรแกรมรันเมื่อคลิกที่ธงเขียว
