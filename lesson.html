เรื่องที่ 1 ความหมายของโปรแกรม Scratch

1.1 ความหมายของโปรแกรม Scratch

Scratch (สแครทช์) คือ ภาษาโปรแกรมในรูปแบบบล็อกคำสั่ง (Block-based Programming) ที่พัฒนาโดย MIT Media Lab เหมาะสำหรับการเรียนรู้การเขียนโปรแกรมขั้นพื้นฐาน ผู้เรียนสามารถลากและวางบล็อกคำสั่งมาต่อกันเพื่อสร้างเกม ภาพเคลื่อนไหว นิทาน หรือดนตรีได้อย่างง่ายดายโดยไม่ต้องพิมพ์โค้ดคำสั่งที่ซับซ้อน

1.2 ส่วนประกอบหลักของหน้าจอ Scratch

เมื่อเข้าสู่โปรแกรม Scratch หน้าจอการทำงานหลักจะแบ่งออกเป็นส่วนสำคัญ ดังนี้:

  • Block Palette (จานสีบล็อก): แหล่งรวมบล็อกคำสั่งตามหมวดหมู่สีต่างๆ เช่น การเคลื่อนไหว รูปร่าง เสียง เหตุการณ์ และการควบคุม
  • Script Area (พื้นที่เขียนสคริปต์): พื้นที่สำหรับนำบล็อกคำสั่งมาวางต่อกันเพื่อสร้างชุดคำสั่งให้ตัวละครทำงาน
  • Stage (เวที): พื้นที่แสดงผลลัพธ์การทำงานของโปรแกรมตามโค้ดที่เราเขียนไว้
  • Sprite List (รายการตัวละคร): ส่วนแสดงตัวละครทั้งหมดที่ใช้งานอยู่ในโปรเจกต์ สามารถเพิ่ม ลบ หรือเลือกตัวละครเพื่อเขียนโค้ดได้

1.3 แนวคิดพื้นฐานในการใช้งาน

การสั่งให้ตัวละคร (Sprite) ทำงานใน Scratch เริ่มต้นจากการเลือกตัวละครและฉากหลัง จากนั้นลากบล็อกเหตุการณ์ (Events) เช่น When [Green Flag] Clicked มาวางเป็นจุดเริ่มต้น และนำบล็อกคำสั่งการกระทำอื่นๆ มาต่อด้านล่าง เพื่อให้โปรแกรมรันเมื่อคลิกที่ธงเขียว

เรื่องที่ 2 ส่วนประกอบของหน้าต่างโปรแกรม Scratch

2.1 แถบเมนู (Menu Bar)

แถบเมนู อยู่ด้านบนสุดของโปรแกรม ประกอบด้วยเมนู File (สร้าง เปิด และบันทึกโปรเจกต์) เมนู Edit และปุ่มเปลี่ยนภาษา

2.2 เวที (Stage)

เวที คือพื้นที่แสดงผลการทำงานของโปรแกรม เช่น ตัวละครเคลื่อนไหวหรือพูดโต้ตอบ ด้านบนเวทีมีปุ่มควบคุม 2 ปุ่ม

  • ธงสีเขียว (Green Flag): เริ่มต้นการทำงานของโปรแกรม
  • ปุ่มวงกลมสีแดง (Stop): หยุดการทำงานของโปรแกรมทั้งหมด

2.3 คลังบล็อกคำสั่ง (Block Palette)

คลังบล็อกคำสั่ง อยู่ตรงกลางหน้าจอ รวบรวมบล็อกคำสั่งแยกตามหมวดหมู่ตามสี เช่น Motion, Looks, Sound, Events, Control ใช้เลือกบล็อกไปสร้างโปรแกรม

2.4 พื้นที่เขียนโค้ด (Code Area)

พื้นที่เขียนโค้ด คือพื้นที่ที่ใช้ลากบล็อกคำสั่งจากคลังบล็อกมาต่อกันเพื่อสร้างชุดคำสั่งให้ตัวละครทำงาน

2.5 แท็บสำหรับจัดการตัวละคร

  • Code (โค้ด): เขียนชุดคำสั่ง
  • Costumes (ชุดแต่งกาย): เปลี่ยนรูปร่างหน้าตาหรือวาดชุดแต่งกายใหม่ให้ตัวละคร
  • Sounds (เสียง): เพิ่มหรืออัดเสียงให้ตัวละคร

2.6 รายการตัวละคร (Sprite List)

2.7 ปุ่มเพิ่มส่วนขยาย (Extensions)

3.2 คำสั่งเริ่มต้นการทำงาน (When Green Flag Clicked)

3.5 การใช้คำสั่งหยุดการทำงาน (Stop)

เรื่องที่ 4 การสร้างตัวละคร (Sprite) และฉาก (Stage)

4.1 ความหมายของตัวละคร (Sprite)

ตัวละคร (Sprite) คือ วัตถุหรือตัวละครที่อยู่บนเวทีของโปรแกรม Scratch สามารถเคลื่อนที่ เปลี่ยนรูปร่าง ส่งเสียง และทำงานตามที่เราสั่งด้วยบล็อกคำสั่งได้ ในหนึ่งโปรเจกต์สามารถมีตัวละครได้หลายตัว และตัวละครแต่ละตัวจะมีชุดคำสั่งเป็นของตัวเอง

4.2 การเพิ่มตัวละครใหม่

การเพิ่มตัวละครทำได้โดยคลิกปุ่มเลือกตัวละครที่ รายการตัวละคร (Sprite List) มุมขวาล่างของหน้าต่าง มี 4 วิธี ได้แก่

  • Choose a Sprite: เลือกตัวละครสำเร็จรูปจากคลังตัวละคร
  • Paint: วาดตัวละครขึ้นมาเอง
  • Surprise: สุ่มตัวละครจากคลัง
  • Upload Sprite: อัปโหลดรูปภาพจากเครื่องคอมพิวเตอร์มาใช้เป็นตัวละคร

4.3 การเปลี่ยนรูปร่างและการลบตัวละคร

หากต้องการเปลี่ยนรูปร่างหน้าตาของตัวละคร ให้เลือกแท็บ Costumes (ชุดแต่งกาย) เพื่อวาดแก้ไขหรือเพิ่มชุดแต่งกายใหม่ ตัวละครหนึ่งตัวมีได้หลายชุดแต่งกาย และใช้บล็อก next costume เพื่อสลับไปชุดถัดไป ทำให้ตัวละครดูเหมือนมีท่าทางเคลื่อนไหว

หากต้องการลบตัวละครที่ไม่ใช้งาน ให้คลิกขวาที่ตัวละครในรายการตัวละครแล้วเลือก delete หรือกดสัญลักษณ์ถังขยะที่มุมของตัวละคร

4.4 ความหมายของฉาก (Stage)

ฉาก (Stage) คือ พื้นที่แสดงผลและเป็นฉากหลังของตัวละครในโปรเจกต์ ทุกโปรเจกต์มีฉากอยู่แล้ว 1 ฉาก ไม่ต้องสร้างเพิ่ม

4.5 การเปลี่ยนฉากหลัง

เมื่อคลิกที่ฉาก (Stage) แล้วเลือกแท็บ Backdrops (ฉากหลัง) จะสามารถเลือก วาด หรืออัปโหลดภาพฉากหลังได้ และสามารถใช้บล็อก next backdrop เพื่อเปลี่ยนไปยังฉากหลังภาพถัดไป

4.6 ความแตกต่างระหว่างตัวละครกับฉาก

  • ตัวละคร (Sprite): เคลื่อนที่ได้ มีบล็อก Motion เพิ่มได้หลายตัว และใช้แท็บ Costumes
  • ฉาก (Stage): ไม่สามารถเคลื่อนที่ได้ ไม่มีบล็อก Motion มีได้ 1 ฉากต่อโปรเจกต์ (แต่มีฉากหลังได้หลายภาพ) และใช้แท็บ Backdrops

6.1 ความสำคัญของการหยุดการทำงาน

ในการเขียนโปรแกรมหรือสร้างเกมด้วย Scratch เมื่อถึงเงื่อนไขที่สิ้นสุดเกม (เช่น เกมโอเวอร์ หรือชนะเกม) จำเป็นต้องมีคำสั่งเพื่อยุติการทำงานของสคริปต์หรือโปรแกรม เพื่อไม่ให้ตัวละครขยับเขยื้อนหรือทำงานซ้ำซ้อนต่อ

6.2 บล็อกคำสั่ง Stop

บล็อก stop () เป็นคำสั่งในกลุ่ม Control (ควบคุม - สีส้ม) ซึ่งมีตัวเลือกการทำงานหลักๆ ดังนี้:

  • all: หยุดการทำงานของสคริปต์และโปรแกรมทั้งหมดในโปรเจกต์
  • this script: หยุดการทำงานเฉพาะบล็อกชุดคำสั่งที่กำลังทำงานอยู่ ณ จุดนั้น
  • other scripts in sprite: หยุดสคริปต์อื่นๆ ทั้งหมดในตัวละครตัวนี้ ยกเว้นสคริปต์ที่กำลังสั่งงานอยู่
